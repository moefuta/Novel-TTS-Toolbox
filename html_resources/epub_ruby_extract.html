3提取结果概览 （基础数据统计与语法提示）

✨ 独创词库语法结构速览（导出后由 tts.py 原生完美解析）：
  • 多读音概率分配：お兄ちゃん => おにいちゃん(70%) | おにいさん(30%) 或 汉字 => 读音1(7) | 读音2(3)（等概率）
    直接在「读音」输入框里改即可。每次朗读时按比例随机抽取，权重不必总和为 100（按比例分配）。单值规则与多值规则分开去重，互不干扰。
  • 绝对优先级权重：絶対 => ぜったい <= count:100
    数值越大，越能无视文件加载顺序，强制覆盖其他词典的同词规则。
  • 等价原词合并：二〇日|二十日|20日 => はつか
    用竖线隔开多个原词，会在一行内生成多条等价的独立规则。兼容半角竖线 | 与全角竖线 ｜，自动识别无需手动转换。
  • 人名词典专属阻断（仅限 person_dict*.txt 生效）：
    (結城|明日奈|アスナ) => (ゆうき|あすな|アスナ)
    按顺序严格一一映射，彻底杜绝错配。配合 [suffix] 君 => くん 还能自动纠正称呼读音。

5导出

下载的文本使用标准规则格式（每行 汉字 => 读音），并按以下分组顺序输出：
名词 → 疑似小字 → 原文仅西文 → 原文仅片假名 → 组词 → 单字 → 存疑；组内按出现次数从高到低排列，出现次数大于 1 的词条会追加 <= count:N 标记。
使用方法：把下载的文件直接放进 D:\TTS\replace_rules\ 文件夹里即可（文件名会自动带上 EPUB 书名，方便区分）。保存后无需重启 tts.py，下一次朗读自动生效。
